# W7 Todo V2.0：数据驱动重构

[返回实验目录](../README.md) · [下一周：事件委托](../week8/README.md)

本周将 Todo 应用整理为由 `todos` 状态驱动的结构，实现任务添加、删除、完成状态切换、筛选及 localStorage 持久化。

## 文件说明

- `index.html`：Todo 页面和任务筛选入口。
- `app.js`：状态管理、数据操作、存储、渲染及事件处理。
- `styles.css`：页面样式。
- `test-fixture.html`：12 项浏览器数据流检查。

## 本地运行

在仓库根目录执行 `python -m http.server 8000`，打开 <http://localhost:8000/week7/>。

## 实现要点

- `todos` 是任务状态的唯一来源；添加、删除和切换生成新数组，再调用 `save()` 和 `render()`。
- 筛选只改变显示内容，不修改任务数据；重新加载页面后默认显示“全部”。
- `load()` 校验已保存的数据，损坏 JSON、字段类型错误或重复 ID 会回退为空数组。
- 本周在每个任务项和删除按钮上分别绑定事件，删除按钮使用 `stopPropagation()` 防止触发任务切换；W8 在此基础上改为父容器事件委托。
- `clearCompleted()` 提供批量清理已完成任务的函数，数据流验证页覆盖其边界情况。

## 验证

打开 <http://localhost:8000/week7/test-fixture.html>，点击“运行数据流验证”。

12 项检查涵盖原数组与原对象保持不变、空输入、删除按钮阻止冒泡、筛选不改数据、存取恢复、批量清理边界、损坏存储回退和纯文本渲染。运行测试会覆盖当前来源的 `todos` 数据。

## 课堂简化条件

任务 ID 使用 `Date.now()`，同一毫秒连续添加可能产生重复 ID。`save()` 保留课堂实现，未扩展存储配额耗尽或禁用写入的处理。
